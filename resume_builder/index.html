Local-first • Ollama-ready • No account required

Build a stronger resume with AI coaching.

Paste your current resume, add the job description, and get a fit score, keyword gaps, stronger bullet drafts, and AI coaching that avoids inventing experience. If Ollama is not running, the deterministic resume coach still works.

Run locally

Start the app from the repo root: 

python3 -m resume_builder.server

Optional: run Ollama on port 11434 and set RESUME_BUILDER_MODEL to your preferred model.

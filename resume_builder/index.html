On-device only - no account required

Build a stronger resume without sending it anywhere.

Paste your current resume, add the job description, and get a fit score, keyword gaps, stronger bullet drafts, and a safe offline prompt you can copy if you choose to use another AI tool later.

Privacy-first MVP

This version runs entirely in your browser or Android WebView. Resume text, job descriptions, and generated coaching are not sent to a server by this app.

For local desktop preview, serve this folder with any static file server or run python3 -m resume_builder.server.
